## Objectif
Créer un README.md complet et professionnel pour un projet.

## Déclencheurs
- Nouveau projet nécessitant une documentation d'entrée
- README existant incomplet ou obsolète

## Étapes
1. Titre + description en une ligne + badges (build, coverage, license)
2. Section Quick Start avec installation en 3 commandes max
3. Exemples de code fonctionnels et copiables
4. Architecture / structure du projet
5. Contributing guide + License

## Outils utilisés
- file_read, file_write

## Critères de succès
- Un nouveau développeur peut démarrer en moins de 5 minutes
- Tous les exemples de code sont testés et fonctionnels
