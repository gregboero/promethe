## Objectif
Optimiser les prompts pour obtenir des réponses précises et fiables des LLMs.

## Déclencheurs
- Résultats insatisfaisants d'un LLM
- Conception d'un nouveau system prompt
- Besoin de structured output (JSON, code)

## Étapes
1. Définir clairement le rôle et les contraintes dans le system prompt
2. Utiliser chain-of-thought pour les raisonnements complexes
3. Fournir des few-shot examples pour le format attendu
4. Demander explicitement le format de sortie (JSON schema, Markdown)
5. Itérer : tester, évaluer, affiner
