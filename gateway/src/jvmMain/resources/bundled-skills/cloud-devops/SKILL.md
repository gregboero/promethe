## Objectif
Concevoir et déployer de l'infrastructure cloud avec les bonnes pratiques.

## Déclencheurs
- Mise en place d'un pipeline CI/CD
- Configuration d'infrastructure cloud (VPC, ECS, Cloud Run)
- Écriture de manifestes Kubernetes ou Terraform

## Étapes
1. Choisir le provider et les services adaptés au besoin
2. Écrire l'IaC (Terraform, CloudFormation, ou Pulumi)
3. Configurer le pipeline CI/CD (GitHub Actions, GitLab CI)
4. Implémenter monitoring et alerting
5. Documenter l'architecture et les runbooks

## Outils utilisés
- execute_command, file_write, file_read

## Critères de succès
- Infrastructure reproductible via IaC
- Pipeline CI/CD fonctionnel
- Monitoring en place
