## Objectif
Produire une documentation technique claire et maintenable.

## Déclencheurs
- Nouvelle API à documenter
- Architecture système à expliquer
- Guides d'intégration ou de migration

## Étapes
1. Identifier l'audience (développeur junior, senior, ops)
2. Structurer : Vue d'ensemble → Concepts → API Reference → Exemples
3. Utiliser des diagrammes pour l'architecture (Mermaid)
4. Fournir des exemples de code pour chaque endpoint/fonction
5. Inclure les erreurs courantes et le troubleshooting

## Outils utilisés
- file_read, file_write

## Critères de succès
- Documentation navigable avec table des matières
- Chaque concept illustré par un exemple concret
