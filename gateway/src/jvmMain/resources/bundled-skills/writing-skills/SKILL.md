## Objectif
Améliorer la qualité et l'efficacité des skills existants.

## Déclencheurs
- Skill existant avec des résultats insatisfaisants
- Besoin d'optimiser les instructions pour un agent

## Étapes
1. Lire le skill existant et identifier les faiblesses
2. Vérifier que chaque étape est actionnable (verbe d'action + résultat attendu)
3. Ajouter des garde-fous (quand NE PAS utiliser ce skill)
4. Optimiser la description pour un meilleur matching automatique
5. Tester le skill sur un cas d'usage réel

## Outils utilisés
- file_read, file_write

## Critères de succès
- Chaque étape commence par un verbe d'action
- Critères de succès mesurables
