## Objectif
Faire une veille technologique sur les 30 derniers jours.

## Déclencheurs
- Question sur les tendances actuelles ou récentes
- Besoin de savoir ce qui buzz dans la communauté tech

## Étapes
1. Chercher sur Reddit (r/programming, r/webdev, r/machinelearning)
2. Consulter HackerNews pour les sujets trending
3. Vérifier les blogs techniques majeurs
4. Filtrer par date (30 derniers jours uniquement)
5. Résumer les tendances principales avec liens

## Outils utilisés
- web_search, http_fetch

## Critères de succès
- Au moins 3 tendances identifiées avec sources datées
- Résumé concis et actionnable
